# Geographic Information Retrieval (2026W)

University of Vienna · Winter Semester 2026/27

Student-facing static course website for *Geographic Information Retrieval*.

## Repository structure

- `index.html` — course homepage
- `week1.html` … `week11.html` — weekly pages
- `slides/` — published lecture slides
- `code/weekN/` — published lab notebooks and supporting files
- `img/` — website assets

The GitHub repository is the canonical published copy for students. Working files may also exist in Google Drive.
