# Geographic Information Retrieval (2026W)

University of Vienna · Winter Semester 2026/27

Static course website for *Geographic Information Retrieval*.

## Preview locally

Open `index.html` directly, or serve the folder with any static web server, for example:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Updating the site

- Shared course metadata, navigation, and weekly topics live in `script.js`.
- Homepage content and policies live in `index.html`.
- Weekly detail content lives in `week1.html` through `week11.html`.
- Put downloadable slides in `slides/` and notebooks/data in `code/weekN/`.
- Items that are not yet confirmed are visibly marked **To be announced**.
